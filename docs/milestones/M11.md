# M11 — Brain on Kùzu; FalkorDB removed; embeddings optional; auto-index

**Status:** ✅ complete

## Intent
Make Plex genuinely "single command, done": no Docker, no service. The brain was the only thing forcing FalkorDB (and the ADR-16 SIGSEGV class). Kùzu — already embedded for the code graph — can hold the brain too (ADR-30).

## What was built
- **Kùzu brain** (`engine/brain.ts`): a `Brain` class over a per-repo `brain.kuzu` with `Round`/`Finding`/`Verdict`/`Comment` node tables keyed by target (`outcome=''` sentinel; `MERGE … ON CREATE/ON MATCH`). One handle per review, **shared** across all brain I/O (`submitVerdict`/`reconcile`/`review` thread it — no nested opens). `repoPaths.brainDir`.
- **FalkorDB removed entirely**: `falkor.ts`, `falkor-worker.mjs`, the `falkordb` dependency, `setup.ts` (Docker), `config.falkordb`, `PLEX_FALKORDB_URL`, `db:up`/`db:down`, `--falkor`, `plex up`/`down`, the compose service, the tsup external + worker copy.
- **Embeddings optional** (`review.ts`): without a provider the brain still records rounds/findings; only the semantic signals (unexplained changes + fix inference) are skipped — no hard "key required" gate.
- **Auto-index on first review**: a never-indexed repo is built in an *isolated child* (so the review process opens Kùzu only once for neighborhood + once for brain), so `plex init`/`plex index` aren't required per-repo.
- **Simplified setup**: `plex init`/`doctor` drop all Docker/FalkorDB. Tests + `brain-check.mjs` ported off FalkorDB (all Kùzu; tsx scenarios kept to ≤2 Kùzu opens per ADR-17, the full-review E2E stays a node check).

## Acceptance criteria
- [x] Brain reads/writes on Kùzu: rounds, findings, comments, `markFindingOutcome` resolves a finding (the `brain` scenario).
- [x] A pushed fix auto-accepts the addressed finding + is idempotent (the `reconcile` scenario, one Kùzu open).
- [x] A review with **no FalkorDB, no embedding key, no prior index** auto-indexes and assembles (round 1) — verified under node.
- [x] FalkorDB is gone from deps, config, build, CLI, compose.
- [x] `pnpm typecheck` + `pnpm test` green (51 unit + 11 integration); `pnpm build` + `pnpm test:brain` green.

## Deviations / notes
- **Trade-off accepted:** the FalkorDB Browser viz is dropped (per decision). The durable graph is inspectable in Kùzu Explorer; `review --html` still renders the blast radius.
- ADR-16 (isolated worker) is retired; ADR-07/22's FalkorDB-required stance is superseded by ADR-30. ADR-17's tsx Kùzu open-limit still applies — hence ≤2 opens per tsx scenario and the node brain-check.
- Embeddings still required for the *knowledge write paths* (seed/mine — ADR-13); only the review brain relaxed to optional.
