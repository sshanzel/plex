# M12 — `awareness` findings + `acknowledge`

**Status:** ✅ complete

## Intent
Make "worth-surfacing, not-a-defect" flags first-class. A reviewer noticing *"two emit sites for the same payment event — confirmed intentional"* is valuable; the old taxonomy buried it as a `nit` and the autonomous loop auto-suppressed it as a dismissal. Fix both (ADR-31).

## What was built
- **`severity: 'awareness'`** (core types) — distinct intent, not a defect. Its own **`awareness`** triage bucket (`findings/rank.ts`) — surfaced, ranked separately, never folded into the defect stream or suppressed by prevalence. `severityWeight`/`SEVERITY_RANK` extended.
- **`verdict: 'acknowledge'`** (core types) — for an awareness flag confirmed intentional. `loadWaivers` treats it as a suppressing waiver; `submitVerdict` embeds it (semantic match, ADR-27) but — unlike `reject` — records **no** down-weighting incident. So the same flag goes silent, while a *materially changed* instance (a 3rd site) re-surfaces.
- **Surfaces**: MCP `submit_findings` severity enum + `record_outcome` kind enum; CLI `verdict`; the `plex-reviewer` agent (use `awareness`, present "Worth confirming" separately) and the `pr-review-responder` skill (record `acknowledge`, not `reject`, for confirmed-intentional flags).

## Acceptance criteria
- [x] An `awareness` finding triages to `awareness` (surfaced, not nit, not suppressed).
- [x] An `acknowledge` semantic waiver suppresses the same flag; a materially changed one re-surfaces (`waivers.test.ts`, 3 cases).
- [x] `acknowledge` does not down-weight the knowledge that raised the flag (no reject-incident).
- [x] `pnpm typecheck` + `pnpm test` green (54 unit + 11 integration); `pnpm build` green.

## Notes
- Modeled as a 4th `severity` value (matches "instead of nit, call it…") rather than a separate axis — simplest, and triage keeps it out of the defect ordering.
- Reuses the ADR-27 semantic-waiver machinery verbatim for the "suppress unless it changes" behavior; the only new bits are the bucket and the no-down-weight on `acknowledge`.
