# M2 — Precision & determinism

**Status:** ✅ complete

## Intent
Turn the raw review loop into a rigorous one: a merged, ranked finding stream (first-principles + knowledge + deterministic), codified checks, precise alias-aware coupling, scoped waivers, and the human-editable `plex.md` surface.

## What was built
- **`findings`** package (pure): `dedupeFindings` (cross-source merge + noisy-OR confidence + `agreedSources`), `computeSignal` (severity × confidence × blast × deviation × agreement), `rankFindings` triage — waived → suppressed, common bug → systemic-migration, common non-bug → convention, else surface (ADR-04/05).
- **`deterministic`** package: built-in TS-AST checks (`no-debugger`, `no-explicit-any`, `no-loose-equality` with `== null` exemption, `no-console`, `no-empty-catch`, `no-await-in-loop`), scoped to changed lines; `detectExternalTools` extension point for Semgrep/ast-grep.
- **Precise edges** (`code-graph/precise.ts`): TS compiler module resolution resolves tsconfig `paths`/`baseUrl` aliases the relative resolver misses → `Refs` edges → `precise-ref` provenance in the neighborhood (ADR-15).
- **`plex.md`** loading into the review context (ADR-09, human steering surface).
- **Engine**: `getDeterministicFindings`, `rankReviewFindings` (merge agent + deterministic + waivers), functional waivers (`loadWaivers` from identity-bearing verdicts).
- **MCP**: `get_deterministic_findings`, `submit_findings` (returns the ranked stream), richer `record_outcome` (waiver identity). **CLI**: review shows deterministic findings + `plex.md`; `verdict` captures waiver identity.

## Deviations / notes
- Deterministic external tools (Semgrep/ast-grep) are an extension point; the built-in TS checks are the always-available baseline so the product never depends on external installs.
- Prevalence is not yet computed from the graph (findings default to non-prevalent ⇒ surfaced); wiring real prevalence is a later refinement.
