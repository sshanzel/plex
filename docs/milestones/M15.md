# M15 — Python language support

**Status:** ✅ complete

## Intent
Plex reviewed only TS/JS. Python is one of the most-used languages, and ADR-15 had promised
"other languages plug in behind the same extractor interface" — an interface that never existed
in code: TS extraction was hardcoded, and a `TS_EXTS` allowlist duplicated across three gates
silently dropped `.py` files from discovery, incremental deltas, and deterministic checks alike.

The intent: Python gets the SAME tripod as TS, at the same rigor — blast radius (imports +
co-change over the real module semantics: `__init__.py` barrels, relative/dotted imports, src
layouts, namespace packages), a deterministic check layer (Python classics included), and the
learned-knowledge loop (whose `Pitfall.language`/`global@py` gating was already multi-language,
ADR-39) — with zero new config and no native dependency risk beside Kùzu. See **ADR-52**.

## What is built
- **The language-plugin seam** (`@plex/core` `lang.ts`): `LanguagePlugin { id, exts, init?,
  extract, resolve }` + the lifted `ExtractedSymbol`/`ExtractedFile` contract + the single
  `EXT_LANG`/`languageOf` registry (moved from the engine). Dispatch by per-consumer capability
  maps; `code-graph/build.ts`'s full + incremental paths share one `extractAndResolve` helper.
  The TS refactor is behavior-identical (commit 1 landed green with zero test churn).
- **`@plex/lang-python`**: web-tree-sitter (WASM) + the prebuilt tree-sitter-python grammar —
  no native build, lazy idempotent init (TS-only repos never load the wasm), mandatory
  `tree.delete()`. Extractor with TS-parity granularity (`Class.method` methods, decorator spans,
  `__all__`/underscore `exported`, PEP 695 `type`); fileSet-pure module resolver (deepest-first
  walk-down; `Imports` edges only — Refs stays the TS config-aware enrichment layer, ADR-06).
- **7 Python deterministic rules** (`deterministic/builtin-py.ts`) with a dotted
  `enclosingSymbol` matching the graph's naming (ADR-47/48 keys align), per-language prevalence
  denominators (ADR-05), and ERROR-subtree tolerance. Rule ids are 1:1 per language.
- **Rollout safety**: `Meta.graphVersion` — a pre-upgrade graph forces one `FullRebuildRequired`
  full re-index so existing (unchanged) `.py` files become visible; discovery skips
  `venv`/`__pycache__`/`site-packages`/`*.egg-info`; `.pyc` + `_pb2(_grpc).py` are generated
  artifacts. Packaging: web-tree-sitter/tree-sitter-python stay external in the tsup bundle;
  the grammar wasm resolves via `createRequire` from dev, dist, and npx installs alike.

## Verification
- **Units (624 green)**: `extract-py.test.ts` (every import form incl. star/TYPE_CHECKING/
  try-fallback/dynamic-literal; decorated spans; `__all__`; nested-def naming; ERROR tolerance),
  `resolve-py.test.ts` (flat/src/monorepo layouts, submodule-vs-symbol ambiguity, PEP 420 under
  src, deterministic tie-breaks, self-import skip), `builtin-py.test.ts` (each rule + non-trigger
  counterexamples; except-clause priority = one finding; the **cross-pin**: deterministic
  `enclosingSymbol` ≡ graph extractor symbol for the same def), runner additions (a `.py` diff is
  analyzed — flipping the old silent skip; mixed diff → one stream; per-language prevalence
  0.5-not-0.2), providers (`_pb2`/`.pyc` generated, authored `.py` not).
- **Integration (24 scenarios green)**: `py-graph` (src layout → dotted symbols, barrel
  transparency, import+co-change blast radius), `py-incremental` (a changed `.py` no longer
  dropped from the delta), `py-mixed` (one graph, one deterministic stream across TS+py),
  `graph-version` (old graph → `FullRebuildRequired`).
- **Shipped-runtime E2E** (`scripts/py-check.mjs`, in `test:e2e`): the built `dist/plex.js`
  resolves the wasm from node_modules, indexes a src-layout repo (3 files / 4 symbols / 3
  imports), walks the blast radius, and a `plex review` surfaces `mutable-default-arg` +
  `no-print` — the packaging risk no tsx/vitest lane can pin.
- **Dogfood — flask** (shallow clone, real src layout + `src/flask/__init__.py` barrel):
  `plex index` → **83 files, 1,620 symbols, 190 import edges in ~2.0s** (WASM parse throughput
  ≈19ms per 3,900-line file, flat RSS with `tree.delete()`). Blast radius of `src/flask/app.py`
  → 26 neighbors led by `globals.py`/`ctx.py`/`sessions.py`/`testing.py`/`cli.py` — Flask's real
  couplings. A planted diff (`def _debug_helper(opts=[])` + `print(...)`) surfaced BOTH findings
  anchored to `symbol: _debug_helper` (ADR-48 location-scoped suppression live for Python), with
  the changed-symbol map catching `Flask`.
- Quality floors (`ranking-quality`, `retrieval-quality`) untouched and green — no retrieval or
  ranking code changed.

## Scope notes (deliberate)
`.pyi` (the `.d.ts` analog), `.ipynb`, `.pyw`, venv/`sys.path`/editable installs, and
type-checker-precise Refs are out of scope — documented with reasons in ADR-52 and
`docs/design/python-support.md` (which also records the REJECTED deterministic rules and why).
Incremental re-resolution of unchanged importers after a new `pkg/name.py`/`__init__.py` lands
matches TS's identical `index.ts` limitation; a full rebuild heals.
