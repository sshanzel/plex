# M8 — Truly incremental co-change + semantic waiver suppression

**Status:** ✅ complete

Closing the two follow-ups M7 deferred — "leave nothing behind."

## 1. Truly incremental co-change (ADR-26)
M7's incremental index re-parsed only changed files but **recomputed co-change fully**. M8 makes co-change incremental too.

- `readCommits(repo, max, sinceRef?)` — restrict to `sinceRef..HEAD`.
- `updateCodeGraph` co-change: crawl only `storedSha..HEAD`; aggregate at full recency (the `Math.max(0, now−ts)` clamp); **strong** pairs (≥`minPairCount` in the window) `MERGE … ON CREATE/ON MATCH SET` (create-or-accumulate); **weak** pairs `MATCH … SET` (accumulate into already-stored pairs only — never create singletons, preserving ADR-06 denoising).
- No epoch bookkeeping needed; decay re-baselines on full builds.

**Result:** incremental index is now O(changed files) for TS *and* O(new commits) for co-change. Verified: `cochange-inc` scenario (cnt 3 → 4 via merge, no re-crawl).

## 2. Semantic waiver suppression (ADR-27)
Waivers matched by exact identity, so "I said ignore it" resurfaced after line drift / rewording. M8 makes pattern/category waivers match by **meaning**.

- `Waiver`/`Finding` gain optional `embedding`.
- `waiverMatches(f, w, semanticThreshold?)` — pattern/category scopes also match when `cosine(w.embedding, f.embedding) ≥ threshold`; `line`/`file` stay exact; default threshold disables it (back-compat). Pure + unit-tested.
- `submitVerdict` embeds a waive-time title (best-effort, real provider only); `rankReviewFindings` embeds findings and passes the `0.82` threshold when any waiver carries an embedding.

**Result:** a waived issue stays waived across rounds despite moved lines and reworded titles. Verified: `waivers.test.ts` (semantic match, precise-scope exactness, back-compat) + `semantic-waiver` scenario (waive → suppressed next run; unrelated finding untouched).

## Deviations / notes
- A co-change pair below `minPairCount` in *every* window stays pruned until a full rebuild (intended; `plex index` without `--incremental` re-baselines).
- Semantic waiver matching needs a real embedding provider (already required for the M6 brain); without one it degrades to the exact identity matcher.
- Threshold `0.82` is a module constant; promote to config if real-world tuning calls for it.
