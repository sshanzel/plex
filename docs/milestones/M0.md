# M0 — Scaffolding & docs framework

**Status:** ✅ complete

## Intent
Stand up the monorepo, shared types, the MCP server skeleton wired end-to-end through diff ingestion, and the documentation/traceability backbone — so every later milestone has a place to plug in and a record to check against.

## Scope
- pnpm + TypeScript (ESM) monorepo with tsx/vitest tooling.
- `core` shared types, config, provider interfaces.
- `ingest` diff adapters (local git + gh PR) normalizing to `NormalizedDiff`.
- `mcp-server` stdio skeleton: `get_review_context` wired through ingest; later tools registered as explicit stubs.
- `docs/`: architecture doc, ADR decision log (15 ADRs), this milestone record.

## Acceptance criteria
- [x] `pnpm install` clean.
- [x] `pnpm typecheck` passes across all packages.
- [x] `pnpm test` green.
- [x] MCP server completes a real JSON-RPC `initialize` + `tools/list` handshake and lists all 6 tools.
- [x] `getLocalDiff` produces a correct normalized multi-file diff from real `git diff` output (added/modified/deleted statuses + changed line ranges).
- [x] Architecture doc + ADR log committed.

## Deviations / notes
- **ADR-15:** chose the TypeScript compiler API over tree-sitter for the v1 language plugin (recorded in the decision log).
- A hand-written multi-file diff sample mis-parsed under `parse-diff` (synthetic `/dev/null` headers); replaced with a real-git integration test, which is both more trustworthy and exercises the production path. `parse-diff` handles real `git diff` output correctly.
