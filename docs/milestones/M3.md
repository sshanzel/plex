# M3 — Knowledge layer

**Status:** ✅ complete

## Intent
Make the reviewer learn: a curated, provenance-backed knowledge base retrieved at review time (RAG, not fine-tuning — ADR-01), seeded from `plex.md`, grown by the feedback loop.

## What was built
- **`knowledge`** package:
  - Pluggable **embeddings** (ADR-13): deterministic `Fake` (tests), `OpenAI` (`text-embedding-3-small`), `Voyage` (`voyage-code-3`), local `Ollama`; `createEmbeddingProvider` factory.
  - **`KnowledgeStore`** — JSON-backed pitfalls + incidents (ADR-18).
  - **`retrieveRelevant`** — cosine similarity over pitfall embeddings, top-K + min-score.
  - **`seedFromMarkdown`** / `parseMarkdownPitfalls` — cold start from `plex.md` (## = category, bullets = pitfalls); idempotent by title.
  - **`recordIncident`** — provenance for the feedback loop.
- **Engine**: `getRelevantKnowledge`, `buildKnowledgeQuery` (from changed symbols + deterministic titles + files), `seedKnowledge`, `learnIncident`, and `submitVerdict` (records a verdict and, on `accept`, writes a knowledge incident — ADR-10).
- **Review context** now includes retrieved `knowledge`.
- **MCP**: `get_relevant_knowledge`, `seed_knowledge`; `record_outcome` now learns on accept. **CLI**: `seed` command, knowledge shown in `review`, `verdict` learns on accept.

## Acceptance criteria
- [x] `pnpm typecheck` clean.
- [x] `pnpm test` green: 25 unit + 7 integration scenarios.
- [x] Retrieval ranks the relevant seeded pitfall first; idempotent seeding.
- [x] Review context retrieves relevant pitfalls (integration + CLI E2E).
- [x] Feedback loop: `accept` writes an incident (`outcome: accepted`).
- [x] Knowledge config is global (`knowledgeDir`, env `PLEX_KNOWLEDGE_DIR`).

## Deviations / notes
- **ADR-18:** knowledge stored as JSON (not Kùzu) — small corpus, embedding retrieval, avoids compounding the Kùzu/tsx open-limit.
- Mining/distillation (M4) — the pipeline that *populates* knowledge from PR history — is intentionally out of scope. Knowledge is currently populated by markdown seeding + the accept-feedback loop.
